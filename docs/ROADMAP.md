# Roadmap

## v1.0 (shipped)

- Android chat app talking to a local Ollama server
- Onboarding, settings, model management, connection testing
- Streaming chat with context budgeting
- Image + text file attachments
- Light / Dark / System theming
- Search across chats

## Next

- **iOS build** — EAS iOS profile, TestFlight
- **Vision models** — richer image handling, multi-image prompts
- **Voice input / output** — speech-to-text and TTS
- **RAG / file indexing** — index local documents for retrieval
- **Multi-provider** — LM Studio, OpenAI-compatible endpoints
- **Sync** — optional encrypted sync across devices
- **Markdown rendering** — richer message formatting
- **Tool calling** — expose local tools to models
